Other bundled frontend components
---------------------------------
FRONTEND-LICENSES.md is generated at build time from the JavaScript bundles.
It lists bundled packages and the notices supplied in their npm packages.
Tauri-LICENSE-MIT.txt supplies the MIT license for the Tauri JavaScript API
and the opener and updater JavaScript packages, which also declare Apache-2.0
as a licensing option.
